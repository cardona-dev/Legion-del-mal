BLOQUES DE CÓDIGO
Tres comillas invertidas y el lenguaje activan el resaltado de sintaxis:
```js
const suma = (a, b) => a + b;
console.log(suma(2, 3));
```

AVISOS · alerts de GitHub
> [!NOTE]
> Información útil para el lector.
> [!WARNING]
> Algo que requiere atención.
También existen [!TIP], [!IMPORTANT] y [!CAUTION]; GitHub los pinta
con color e icono.
CONSEJOS DE MARKDOWN
Deja una línea en blanco entre párrafos; si no, se unen en
uno solo.
Termina una línea con dos espacios para forzar un salto sin
párrafo nuevo.
Escapa un símbolo especial con \\ delante (p. ej. \\*).
Previsualiza con la pestaña Preview antes de guardar.
